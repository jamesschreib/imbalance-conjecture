# Imbalance Conjecture

The Imbalance Conjecture states that, for every finite simple graph \(G\) with \(d_G(u) \ne d_G(v)\) on each edge \(uv\), the multiset \(\{|d_G(u)-d_G(v)| : uv \in E(G)\}\) is the degree multiset of a finite simple graph.

Formalized in Lean 4.30, including a self-contained proof of Erdős–Gallai sufficiency. Reproduce the verification by running `lake build`.
